# NutriShield AI — Instant Food Safety & Guidance

NutriShield AI is a compact, demo-ready Streamlit app that turns a photo of a packaged food label into an immediate, consumer-friendly safety verdict and a clinician-grade technical deep-dive. Built and localized for Bangladeshi contexts, it pairs a simple visual dashboard with an evidence-backed explanation.

Key highlights

- One-click demo mode with a sample product for fast presentations.
- Upload a label photo (JPG/PNG) and receive a traffic-light verdict (Green/Amber/Red) plus an actionable mini-summary.
- Detailed technical deep-dive in a collapsible panel for clinicians and researchers.
- Localized serving suggestions using familiar household measures and a compact additives lookup.

---


## Quickstart

Install and run

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Notes

- Set your Gemini API key via environment variable or a secret manager; do not keep keys in `app.py`.
- Use the demo button for a fast, presentation-ready run without API usage.
